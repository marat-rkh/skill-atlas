## What was done

- Added a "Filter" section to `spec/app.md`. The map page got a filter field; submitting it reloads the page with an
  optional `filter` query parameter, e.g. `/scan?repo=https://github.com/JetBrains/kotlin&filter=test`, so a filtered
  map can be bookmarked or shared.
- A skill matches if its name or description contains the text, ignoring case and leading or trailing whitespace. Groups
  with no matches are hidden.
- The page shows how many skills match, e.g. `2 of 6 skills match "test"`, or says that none do. An empty filter shows
  the whole map.
- The filter is web-only; the CLI is unchanged.
- The tests in `web_test.go` cover matching, hiding groups, the count line, empty filters, repos without skills,
  escaping, and filtering a real local git repo.
