# General guidelines

## Memory

Read `.agents/memory` subfolder for history of activity in this project.
Also update it after each logical block of work, or session is finished.

## Definition of 'Done'

- Each part of the spec should be covered with tests. Tests should pass locally.
- When we finish work and create a merge request, we wait for build and test on CI to be green. 
If it is red, we check the logs and make necessary fixes until all is green.

## Demos

When working in the cloud, record a demo of new features so that reviewers can check it in the PR.
